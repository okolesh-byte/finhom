# Finhom

Персональная веб-система учёта личных финансов с модулем прогнозирования и предупреждения финансовых рисков.

## Возможности первой версии

- регистрация и вход по электронной почте;
- профиль с датой рождения и фотографией;
- учёт доходов и расходов;
- месячные бюджеты и обязательные платежи;
- накопительные конверты;
- аннуитетные кредиты, график платежей и досрочное погашение;
- прогноз баланса и оценка финансовых рисков;
- прогноз на 3, 6 и 12 месяцев при достаточной истории;
- возрастная рекомендация по размеру финансового резерва;
- выгрузка операций в CSV;
- финансовые статьи, комментарии с модерацией и предложения тем;
- страница модератора и административная панель Django;
- восстановление пароля по электронной почте.

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:DJANGO_SECRET_KEY = python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`.

Секретные настройки хранятся в переменных окружения. Файл `.env` и рабочая база данных не должны отправляться в публичный репозиторий.

`.env.example` содержит только образец настроек. Файл `.env` автоматически не загружается: переменные нужно задать в терминале или настройках окружения. Команда выше создаёт ключ для текущего сеанса PowerShell, не записывая его в код. Для постоянной установки храните один ключ в защищённых настройках окружения. Без заданного ключа режим разработки создаёт временный ключ; после перезапуска сеансы входа и ссылки восстановления могут стать недействительными. При `DJANGO_DEBUG=False` запуск без ключа запрещён.

В режиме разработки письмо для восстановления пароля выводится в терминал, где запущен сервер.

## Демонстрационные данные

```powershell
python manage.py seed_demo
python manage.py seed_test_accounts
python manage.py seed_community
python manage.py seed_articles
```

Команды можно запускать повторно. Пароли печатаются только при создании новых аккаунтов. Повторный запуск `seed_test_accounts` обновляет демонстрационные финансовые данные, сохраняя действующие пароли.

Смена пароля доступна из профиля. Вход по электронной почте не зависит от регистра букв.

Операции отражают фактически полученные и потраченные деньги. Будущие записи не входят в баланс и прогноз. Отметка платежа в банковском графике не создаёт денежную операцию: расход по кредиту учитывается в категории «Кредиты». Остаток задолженности пользователь переносит из банка.

Прогноз использует средние данные завершённых месяцев, обязательные расходы и оставшийся срок кредитов. При неполном первом месяце прогноз предварительный. Возрастной резерв — простое правило учебной модели (3, 6 или 12 месяцев), а не персональная финансовая рекомендация.

Для сотрудника-модератора задайте `is_staff` и нужные права `change_comment`, `change_topicsuggestion`, `change_article` в Django Admin. Разделы и действия доступны согласно назначенным правам.
